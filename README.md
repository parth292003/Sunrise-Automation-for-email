# Sunrise Natural Stones — German Distributor Automation Web Application

Luxury web application matching the design system of **[www.sunrisenaturalstones.com](http://www.sunrisenaturalstones.com)** for automating 1-on-1 personalized outreach proposals to German Tombstone & Gravestone Wholesalers and Manufacturers.

---

## 🌟 Key Features

- **Luxury Design System**: Built with the exact typography, ivory stone backgrounds (`#FAF8F5`), charcoal text (`#2A2825`), and golden amber logo accents (`#C87A1E`) matching `www.sunrisenaturalstones.com`.
- **Strict Sender Locking**: Pre-configured and locked to **`contact@sunrisenaturalstones.com`**.
- **1-on-1 Individual `TO` Emails (No BCC)**: Every single company receives a dedicated, 1-on-1 personalized email with their domain email in the `TO` field.
- **Attachment Pre-Set**: Includes **`Sunrise Natural Stones.pdf`** proposal attachment and digital catalog link.
- **Excel Dropzone**: Pre-loaded with 103 verified German tombstone companies + drag-and-drop support for any custom Excel/CSV list.
- **Immediate & Scheduled Modes**: Option to launch 1-click compose or set a scheduled CET business hours timer.
- **Automated Excel Exporter**: Allows downloading the dataset as an automated `.xlsx` file with embedded `=HYPERLINK` formulas.

## 🚀 How to Host on GitHub Pages (Free 1-Click Deployment)

1. **Create a GitHub Repository**:
   - Go to [github.com/new](https://github.com/new).
   - Repository Name: `sunrise-automation` (or any name you prefer).
   - Set visibility to **Public** or **Private** (GitHub Pages supports both).

2. **Upload Repository Files**:
   - Upload `index.html`, `styles.css`, `app.js`, and `README.md` to the main branch.

3. **Enable GitHub Pages**:
   - Click **Settings** (top menu of your GitHub repository).
   - Scroll down to **Pages** (on the left sidebar).
   - Under **Build and deployment** -> **Source**: Select `Deploy from a branch`.
   - Branch: Select `main` / `/ (root)` -> Click **Save**.

4. **Your Live Web Application URL**:
   - GitHub will generate your live URL in ~60 seconds:
     `https://your-username.github.io/sunrise-automation/`
